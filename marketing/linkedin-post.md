I use Claude Code on two accounts: one personal, one for work.

Every switch looked the same: `claude auth logout`, sign in again, lose my place, then find out an hour later that I'd been running work on the wrong plan.

So I built **ClaudeSwap**, a free, open-source VS Code extension and Claude Code plugin.

✻ Your active Claude account sits in the status bar
⚡ Switch accounts in one click, or type `/account` in Claude Code chat
📌 Pin an account to a project. Your work repo always runs on the work account, with no switching needed
⇄ Run two projects on two accounts side by side, in separate windows
🔒 Tokens stay in the macOS Keychain or a 0600 file, the same places Claude Code already uses

Sign in once with each account and ClaudeSwap remembers it. There's nothing to set up.

To try it, search "ClaudeSwap" in the VS Code Extensions view.
Code: github.com/LogicalAngel/claudeswap
